# Тестовые сценарии и ограничения — Astana Walk

Документ для сдачи по треку НИЦ Smart City («Документ с описанием тестовых сценариев и ограничений»). Описывает концепцию, 14 проверяемых сценариев с фактическим результатом, обработку сомнительных данных, ограничения, этику и приватность. Архитектура и RAG описаны в [README.md](README.md), порядок демо — в [HACKATHON.md](HACKATHON.md), происхождение данных — в [NOTICE.md](NOTICE.md), поля API — в [API.md](API.md).

## 1. Концепция продукта

**Идея.** У жителя или гостя Астаны есть ограниченное время: 30 минут, два часа, вечер. Каталог показывает тысячи мест, но не проверяет, успеет ли человек дойти и посетить место до закрытия. Astana Walk отвечает на запрос обычным языком («хочу тихое кафе с розеткой», «нас 5, хотим поужинать») 1–3 конкретными местами. Для каждого места есть время пешком по реальному графу OSM, оценка времени на посещение, проверка расписания на момент прихода, пояснение «почему» и идея «что делать». Факты (цены, часы, расстояния) формирует backend из данных. Gemini выбирает только ID из найденных кандидатов и пишет пояснения. Если модель недоступна, работает локальный поиск.

**Аудитория.**

| Кто | Что важно |
|---|---|
| Жители | Быстро найти, куда сходить рядом, без перебора карточек 2ГИС |
| Туристы | Успеть посмотреть главное за 1–3 часа, в том числе до вылета (с резервом на дорогу и аэропорт) |
| Родители | Детские площадки и центры, интерактивные музеи; детские удобства и цены только если они есть в данных |
| Компании из 3–5 человек | Места с VIP-залом, кабинками, банкетами; бюджет на всех; совет забронировать стол |
| Люди с ограниченной подвижностью | Режим «Без лестниц», отметки о пандусах и доступном входе. Полная доступность не обещается (см. §5) |

**Сценарии использования.** Прогулка заданной длины от выбранной точки; поиск места по удобствам (тишина, розетки, Wi-Fi, работа с ноутбуком); прогулка с ребёнком; мини-маршрут из 2–3 мест; событие во время прогулки (цирк, театр, выставка); ужин компанией; прогулка перед рейсом; вечерняя или ночная активность; запрос на казахском.

**Данные.** 7 431 каноническая POI (из 7 570 исходных записей OSM, 2ГИС, Visit Astana и других источников; 141 слияние). Пешеходный граф OSM: 166 683 узла, 391 338 рёбер. Признаки из отзывов 2ГИС есть у 2 100 мест. В афише 103 записи. Данные собраны 19.10.2026.

## 2. Как получены фактические результаты

- **Дата прогона:** 20.10.2026, по текущему коду из рабочей копии. Другая сессия параллельно правит релевантность в backend, поэтому после её изменений результаты могут поменяться.
- **Способ:** backend запускался в процессе через `fastapi.testclient.TestClient` (`backend/app.py`, `POST /api/chat`), с окружением проекта `.venv` (numpy 2.3.5, scikit-learn 1.8.0, как в `requirements-lock.txt`).
- **Погода** подменена заглушкой `{"available": false}`, как в `tests/test_app.py`, чтобы результат не зависел от Open-Meteo.
- **Gemini:** `GEMINI_API_KEY` пустой, `provider: "gemini"`. Поэтому во всех прогонах работает **локальный fallback**: первые 3 кандидата, `why`/`what_to_do` = `null`. Вместо них в карточке пояснения из данных («Подходит по категории…», «По отзывам 2ГИС: …», «Путь и посещение: ориентировочно N мин») с пометкой «Объяснение собрано из данных места без генерации». Сбой Gemini с HTTP 429 проверен через подмену HTTP-транспорта (T11). Путь с настоящим ответом модели (проверка ID, JSON, тексты «почему»/«что делать») покрыт замоканными тестами `tests/test_app.py` (8 тестов `-k "gemini or provider or safety or invented"` прошли 20.10.2026). Живой вызов Gemini в этом прогоне **не** выполнялся.
- **Время запроса** (`when`), если не указано другое: 2026-10-19 12:00 UTC+5. Это дата снимка данных (см. HACKATHON.md), не текущее открытие.
- **Точки старта:** Бәйтерек = 51.12829, 71.43045; MEGA = 51.089, 71.407 (из `data/landmarks.json`). Если старт назван в тексте («возле Байтерека», «Mega Silk Way»), backend берёт его из текста.

Статусы: ✅ — ожидание выполнено; ⚠️ — частично, есть замечание; ❌ — не выполнено.

Закрытый Нур Алем не подменяется работающим музеем, ответ объясняет закрытие со ссылкой. | «Хочу поужинать в Дареджани»: филиал на Кабанбай батыра, 34 (`temporarily_closed_as_reported_by_2gis`) в ответ не попал, выдан другой филиал (OSM, без статуса 2ГИС). T14 — Нур Алем. |
| **Неизвестные часы** | Часы сравниваются в UTC+5 на момент прихода и всего визита. «По опубликованному расписанию; праздничные изменения не проверены» ≠ проверенное открытие. Без часов — «Перед посещением уточните часы работы»; фильтр «Открыто по расписанию» такие места не пропускает. Живой проверки открытия нет. | T01, T07, T14: монументы, набережная, музеи с неизвестными часами помечены предупреждением. |
| **Временные мероприятия** | Анонсы из `data/events.jsonl` отбираются по времени прогулки и пешей доступности; отменённые, прошедшие и распроданные пропускаются. Всё помечено как опубликованный анонс, «проведение не подтверждено». Проверка источника запрашивает страницу издателя; при сбое показывается неудачная проверка, а не подтверждение (последняя пакетная попытка: 101 запись — источник недоступен, 2 — неподдерживаемый издатель). | T08: шоу «Pro Цирк» 16:00 с пометкой «проведение не подтверждено». |
| **Одно упоминание в отзывах** | Статус `single_mention`: показывается как неподтверждённое, в строгий фильтр не проходит. | T10: «Доступность для коляски: одно упоминание в отзывах…, не подтверждено». |
| **Противоречащие отзывы** | `mixed` (отзывы расходятся) и `contradicted` («против» больше) видны в карточке с цитатами и счётчиками. `supported` требует ≥2 «за» и «против» не больше трети. | T02: у Barista Coffee розетки `contradicted` по отзыву, но `confirmed` по данным места; конфликт сейчас не снижает уверенность (⚠️, см. итог §3). |
| **Свойство отсутствует** | `null` = неизвестно. Отсутствие тега не означает «нет». Цена не придумывается, отсутствие цены ≠ бесплатно; средний чек отличается от билета; тариф одного аттракциона не переносится на весь комплекс. | T03: возраст и цены детских центров не выведены; T02: «Тихая обстановка: нет данных». |

## 5. Ограничения

**Покрытие данных** (из 7 570 исходных записей, `data/dataset_source_summary.json` → `field_coverage`, и `data/quality_report.json`):

| Поле / область | Покрытие |
|---|---|
| Часы работы | 5 080 записей (~67%); ни одна запись не проверена на месте (`hours_verified_at` = 0); праздничные часы — 7 |
| Контакты | телефон 416 (~5,5%), сайт 294 (~3,9%) |
| Категории | еда и напитки 4 265 (56%); культура 96, развлечения 75, достопримечательности 180, тихие места 80; детские 417 |
| Удобства в полях источника | розетки — 2 записи, тишина — 1; остальное только из отзывов 2ГИС (2 100 мест с признаками) |
| Цены | у 2 610 канонических записей есть цена или средний чек; билеты для взрослых — 4 исходные записи, детские — 3 |
| Описания | собственных описаний источника 395; у 4 863 записей описание составлено по атрибутам (`attribute_grounded_summary`), это не независимые отзывы |
| Казахские названия | 92 исходные записи |
| Список пропусков | 7 411 записей с недостающими полями в `data/missing_data_backlog.jsonl` |

**События.** 103 календарные записи — снимок публикаций. Ни одно событие не подтверждено независимо: последняя проверка источников не подтвердила ни одного.

**Маршруты.** Маршрут строится по снимку OSM алгоритмом Dijkstra. Старт и места привязываются к пешеходной сети в пределах 150 м (настраивается: 30–300 м); эти соединения не проверены, `door_to_door_verified` всегда false. Мини-маршрут жадный: перебирает последовательности 16 лучших кандидатов, без обратного пути; глобально оптимальный тур не гарантирован. «Без лестниц» исключает только отмеченные в OSM лестницы. Пандусы, покрытие и доступность для коляски не подтверждаются.

**Время и транспорт.** Общественного транспорта, такси и пробок в реальном времени нет: только пешком. Перед рейсом время дороги и резерв на аэропорт вводит сам пользователь. Погода — модельная оценка Open-Meteo для центра города, а не измерение у заведения.

**Поиск.** TF-IDF по символьным n-граммам с признаками из отзывов. Нет обученной модели релевантности и нет оценки на размеченных запросах. Слова запроса могут совпасть с названиями мест (T06). Рейтинг вносит небольшой сглаженный вклад (prior 4,5 / 245).

**Язык.** Интерфейс на RU/KK; казахские запросы распознаются по ключевым словам. Локальные ответы без модели только на русском (T13).

**Модель.** Gemini работает только через сеть. На бесплатном тарифе около 20 запросов в сутки, на некоторых сетях домен API блокируется (см. HACKATHON.md). Без модели нет текстов «почему»/«что делать», только пояснения из данных.

**Актуальность.** Данные собраны 19.10.2026. Это снимок для демо, а не мониторинг заведений.

## 6. Этика и приватность

- **Минимум данных о пользователе.** Нет базы пользователей, аккаунтов, истории координат и постоянного хранения чатов. Геолокация запрашивается только по кнопке; координаты используются для расчёта маршрута в одном запросе и не сохраняются (`/api/meta` → `location_stored: false`). Локальный сервер запускается без access-log.
- **Что видит Gemini.** Текст запроса и факты кандидатов (название, категория, время пути, сводка отзывов). Точные координаты пользователя не передаются. Если пользователь сам написал адрес в сообщении, этот текст уходит в модель. На бесплатном тарифе Google может использовать запросы для улучшения продуктов, на платном — нет.
- **Внешние сервисы.** Подложка карты OSM видит IP и запросы тайлов; фото 2ГИС загружаются с CDN 2ГИС только при открытии карточки. Шрифт Inter и иконки Lucide поставляются локально.
- **Прозрачность.** Каждая карточка показывает источники с URL и датой сбора. Сгенерированный текст отделён от фактов («Текст: Gemini», `generated_facts: false`). Неизвестное помечено как неизвестное, «открыто» звучит только как «по расписанию». В ответе виден шаг обработки (`steps`): поиск, проверки, кто выбрал места.
- **Отзывы.** Отзывы 2ГИС собраны без данных авторов. Тексты лежат только локально (`collector/output/`, вне Git). В `data/review_signals.jsonl` хранятся счётчики и короткие цитаты до 200 символов со ссылкой на вкладку отзывов филиала, без имён. Это утверждения посетителей, а не проверка на месте.
- **Лицензии.** OSM — ODbL 1.0 (граф — производная работа). Данные 2ГИС подчиняются условиям провайдера и не становятся открытыми из-за включения в архив. Лицензионное соглашение 2ГИС (п. 6.1) ограничивает извлечение материалов, поэтому перед публичным распространением цитат и фото нужно согласование с организаторами и правообладателем. Wikidata — CC0. Подробно — в [NOTICE.md](NOTICE.md).
- **Безопасность пользователя.** Прототип не оценивает криминальную обстановку, стройки и качество переходов на маршруте. Перед рейсом не предлагает прогулку без резервов времени (T04). Доступность для коляски не обещает без данных (T10). Перед публичным хостингом нужны ограничение частоты запросов, TLS и политика обработки данных.

## 7. Как воспроизвести

Через интерфейс: `docker compose up -d --build`, http://127.0.0.1:8090. Нужные условия задаются в «Условиях прогулки» (старт, время, бюджет, «Без лестниц», «Открыто по расписанию», «Только подтверждённые удобства», «Если скоро вылет», «Сколько вас»).

Через API, например T04 (б):

```bash
curl -s http://127.0.0.1:8090/api/chat -H "Content-Type: application/json" -d '{"query":"Я - турист, у меня 2 часа перед вылетом: что можно посмотреть поблизости?","provider":"gemini","latitude":51.1282882,"longitude":71.4304546,"when":"2026-10-19T12:00:00+05:00","airport_transfer_min":30,"airport_reserve_min":60}'
```

С ключом Gemini в `.env` в ответе появятся тексты «почему» и «что делать», а выбор 1–3 мест может отличаться от локального.

Автоматические проверки: `docker compose --profile test run --rm tests` (pytest, модель замокана) и `docker compose --profile test run --rm e2e` (Playwright: сценарии + axe).
