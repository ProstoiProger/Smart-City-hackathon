# Astana Walk — Smart City

ИИ-помощник по прогулкам в Астане. Пользователь пишет, где он, сколько у него времени и чего хочется, а помощник предлагает 1–3 места рядом. У каждого места есть объяснение «почему», время пешком, время на посещение и идея «что делать». Можно построить мини-маршрут из нескольких мест. Под капотом RAG: поиск по собранной базе мест Астаны и генерация объяснений через Gemini API.

Что умеет:
- карта, список мест и чат; интерфейс на русском и казахском, светлая и тёмная тема;
- пешеходные маршруты по реальной сети дорожек OSM, учёт часов работы на момент прихода;
- признаки из отзывов 2ГИС с цитатами («тихо», «есть розетки», «удобно с детьми»);
- мини-маршрут из 3 мест, подбор для компании из 3–5 человек, афиша событий;
- маршрут к следующему делу («через 2 часа нужно быть в MEGA, по пути кофе») или с возвратом к началу, с учётом последнего отрезка и запаса; перестройка на ходу: «здесь закрыто», «потратили ещё 15 минут», «замёрзли», «устали»;
- правка маршрута обычными фразами («первое оставь, второе замени», «без кафе», «ещё варианты, но ближе», «теперь нас четверо»), план Б рядом с каждой остановкой, место встречи для компании из разных точек города;
- учёт погоды и качества воздуха, прогулки с гидом, голосовой ввод, вопросы о конкретном месте, карта «пробелов» города.

## Запуск

Нужен только Docker с Compose v2 (Docker Desktop на Windows/macOS или Docker Engine на Linux).

```bash
cp .env.example .env          # впишите GEMINI_API_KEY (без ключа работает поиск без модели)
docker compose up -d --build
```

| Что | Ссылка |

Карте нужен интернет для подложки OpenStreetMap, чату — доступ к Gemini API.

## Gemini API

Заполните `.env` рядом с `run.py`:

```dotenv
LLM_PROVIDER=gemini
GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-3.6-flash
GEMINI_THINKING_LEVEL=low
```

Ключ остаётся на сервере и не попадает в браузер. На бесплатном тарифе около 20 запросов в сутки на модель, поэтому для демо нужен платный Tier 1. Если ключа нет, квота исчерпана или сеть недоступна, чат показывает причину и отвечает локальным поиском: объяснения в этом случае собираются из данных места.

## Озвучка (ElevenLabs, по желанию)

Голосовые ответы и прогулки с гидом озвучиваются через ElevenLabs. Добавьте в `.env`:

```dotenv
ELEVENLABS_API_KEY=your_key_here
ELEVENLABS_VOICE_ID_RU=voice_id_для_русского   # голоса из вашей библиотеки ElevenLabs
ELEVENLABS_VOICE_ID_KK=voice_id_для_казахского
```

и перезапустите: `docker compose up -d`. Оба языка озвучивает модель Eleven v3 (только она поддерживает казахский); модели меняются через `ELEVENLABS_MODEL_RU` и `ELEVENLABS_MODEL_KK`. Если голос для языка не задан, берётся общий `ELEVENLABS_VOICE_ID`, а без него — стандартный многоязычный голос. Ключ остаётся на сервере, одинаковые фразы кэшируются. Без ключа или при ошибке используется голос браузера.

## Архитектура

```
Сбор данных (офлайн)            collector/, scripts/
   OSM · Visit Astana · 2ГИС · отзывы 2ГИС · афиша · Open-Meteo
        ↓
Готовые данные                  data/   (места, пешеходный граф, поисковый индекс, признаки из отзывов, афиша)
        ↓ загружаются в память при старте
Backend · FastAPI               backend/
        ↓ /api/...              ↘ Gemini API
Frontend · React + MapLibre 3D  frontend/
```

Базы данных нет: все данные лежат файлами в `data/` и держатся в памяти backend.

**Как обрабатывается запрос в чате:**
1. **Разбор запроса.** Старт, финиш и время («я у Экспо», «через 2 часа нужно быть в MEGA», «вечером») читаются правилами. Что человек хочет («хочу рисовать», «на балет», «кофе и посидеть с ноутбуком»), читает Gemini: он выбирает категории и виды мест только из каталога базы, удобства и слова для поиска. Без ключа или при ошибке модели это делают правила, а блок «Учтено» показывает, как понят запрос.
2. **Поиск (retrieval).** Лексический поиск TF-IDF по 7 431 месту, затем фильтры:
   - путь пешком по графу OSM;
   - бюджет времени;
   - часы работы на момент прихода;
   - закрытия.

   Места с подтверждёнными удобствами и хорошим рейтингом поднимаются выше.
3. **Контекст.** Мини-маршрут, события афиши, погода и пожелания компании.
4. **Генерация.** Gemini получает факты найденных кандидатов, выбирает из них 1–3 места и пишет «почему» и «что делать». Ответ проверяется: места, которых нет среди кандидатов, отклоняются. Цены, часы и расстояния на карточках всегда берутся из данных, а не из текста модели. Координаты пользователя в Gemini не отправляются.

## Данные

Датасет собран командой. Сбор автоматизирован скриптами в `collector/`.
- **Источники:** OpenStreetMap (места и пешеходная сеть), Visit Astana, 2ГИС (рейтинги, часы, атрибуты, первая страница отзывов без данных авторов), Ticketon и Sxodim (афиша), Open-Meteo (погода).
- **Объём:** 7 570 исходных записей, после слияния дублей 7 431 место.
- **Признаки из отзывов:** Gemini разметил упоминания удобств в отзывах. Утверждение сохраняется, только если его цитата действительно есть в отзыве.

Данные — снимок на 19.10.2026. Источники и лицензии описаны в [NOTICE.md](NOTICE.md).

## Этика и приватность

**Местоположение пользователя**
- Нет учётных записей, истории координат и сохранённых чатов. Сервер работает без журнала запросов.
- Геопозиция запрашивается только по кнопке, приблизительно. В прогулках с гидом она остаётся на устройстве.
- Координаты пользователя не отправляются в Gemini. Модель получает только текст запроса и факты найденных мест. Если человек сам написал адрес в сообщении, этот текст уйдёт в запрос.
- Внешние сервисы видят минимум: подложка OSM — какой участок карты открыт, CDN 2ГИС — фото открытой карточки. Голосовой ввод работает через распознавание речи браузера; в Chrome оно обрабатывается на серверах Google. Озвучка ответов отправляет в ElevenLabs только текст ответа (названия мест, время пути), без координат.
- На бесплатном тарифе Gemini Google может использовать запросы для улучшения продуктов, на платном — нет.

**Недостоверная и неполная информация**
- Факты (цены, часы, расстояния, маршруты) берутся только из данных. Модель пишет лишь «почему» и «что делать», и этот текст помечен «Текст: Gemini». «Что делать» — идея, а не проверенный факт.
- Нигде не пишется «открыто сейчас». Статусы: «по расписанию открыто к приходу», «закрыто по расписанию», «источник сообщает о закрытии», «часы не подтверждены».
- Удобства из отзывов — утверждения посетителей. У каждого есть статус: подтверждено несколькими отзывами, одно упоминание, отзывы расходятся или скорее нет. Цитаты показаны в карточке.
- Анонсы афиши — публикации организаторов, проведение не подтверждается. Закрытые места (например, прежний музей Нур Алем) не выдаются за работающие.
- Пропуски в данных не заполняются догадками. Неизвестное так и помечено.

**Безопасность**
- Маршрут строится по снимку OSM: криминальная обстановка, стройки и состояние переходов не проверяются.
- Режим «Без лестниц» исключает отмеченные лестницы, но не гарантирует доступность для коляски.
- Резервы времени до вылета — оценки. Требования авиакомпании и пробки не учитываются.

**Данные источников**
- Отзывы 2ГИС собраны без данных авторов. Сырые тексты в репозиторий не попадают, только короткие цитаты к признакам.
- Сбор шёл с паузами между запросами (отзывы — 1 запрос в секунду), сборщик афиши учитывает robots.txt. Источники и условия использования описаны в [NOTICE.md](NOTICE.md).
