# Происхождение

Приложение создано для пользователя по функциональной архитектуре его AFM_project. Новая предметная область — прогулки по Астане. Исходный AFM_project не менялся.

Данные взяты из ранее собранного в aitu_hackathon датасета. Источники и даты сохраняются в каждой POI-записи и в `data/source_registry.json`. Оригинальные неизвестные значения не подменены положительными утверждениями. В приложение дополнительно перенесены отметки о закрытии из уже собранных свежих ответов 2ГИС; повторных обращений к 2ГИС при запуске нет.

- OpenStreetMap: ODbL 1.0, https://www.openstreetmap.org/copyright. Граф и маршруты — производные от снимка OSM. Непроверенные связи с входами не считаются данными OSM о реальной доступности.
- 2ГИС: собственные условия провайдера; сведения не становятся открытой лицензией из-за включения в этот архив. Факт работоспособности ключа не устанавливает право на публичное распространение данных.
- Visit Astana, сайты заведений и другие источники: атрибуция и URL приведены в POI. Для них не заявляется единая открытая лицензия.
- Wikidata: CC0; отдельные фотографии/материалы Wikimedia имеют собственные лицензии. Фотографии не скачиваются и не поставляются приложением.

Архив передан пользователю как результат его работы с датасетом, без автоматической публикации в открытом доступе. Он не предоставляет новых прав на сторонние данные. Отдельно публикуемый код и данные следует учитывать раздельно.

Сторонние программные зависимости сохраняют свои лицензии; npm package-lock фиксирует фактические версии frontend. Документация поставщиков связана в README.

Дополнительные точечные источники версии 2:

- Visit Astana, казахская страница мечети Хазрет Султан: https://visitastana.kz/kz/about-city/what-to-see/ziret-s-ltan-meshiti/ — опубликованные посетительские часы 06:00–20:00, проверено 19.10.2026. Это не проверка открытия на месте.
- Оператор Ailand: https://ailand.kz/ru/attractions/ocean-ru/ и https://ailand.kz/ru/attractions/jungle-ru/ — именованные карточки билетов отдельных аттракционов; сохранены тип билета, валюта, URL, дата и хеш снимка. «Стандарт» не означает автоматически взрослый возраст.
- OpenStreetMap way/full API, объекты 243041606 и 112177946: проверка непересечения полигонов Президентского парка. Отдельные геометрии не устанавливают административное деление.

Составленные по атрибутам описания помечены `attribute_grounded_summary`, исходные тексты сохранены. Это преобразование существующих утверждений источника, не новый независимый отзыв. Сетевые ошибки при проверке афиши сохранены как ошибки, не как подтверждение актуальности.

Отзывы 2ГИС (версия 3): публичные тексты первой страницы отзывов собраны локально (`collector/output/`, исключено из Git) без данных авторов. В `data/review_signals.jsonl` хранятся только производные счётчики и короткие цитаты до 200 символов с датой и ссылкой на вкладку отзывов филиала. Это утверждения посетителей, а не проверка на месте. Условия 2ГИС (лицензионное соглашение, п. 6.1) ограничивают извлечение материалов из их баз: перед публичным распространением цитат проверьте допустимость у организаторов и правообладателя.

Интерфейс (версия 4): шрифт Inter (SIL Open Font License 1.1, https://github.com/rsms/inter) поставляется локально в `frontend/src/assets/fonts`; иконки Lucide (ISC License, https://lucide.dev/license) — спрайт `frontend/src/assets/icons.svg`. Оба ресурса взяты из проекта AFM_project того же автора.

Фото мест (версия 5): главное фото организации показывается только по запросу пользователя (открытие карточки) по публичному адресу CDN 2ГИС, с подписью и ссылкой на страницу 2ГИС; изображения не копируются в проект. Права на фото принадлежат их авторам и 2ГИС; перед публичным использованием проверьте допустимость у правообладателя.
