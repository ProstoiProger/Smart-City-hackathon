# Исходный сборщик датасета

Необязательная часть поставки: исходники коллектора, нормализации, парсеров и их тесты. Готовому приложению они не требуются.

Сборщик запускается в Docker-образе `collector` (цель `collector` в `../Dockerfile`, свои зависимости из `requirements.txt`). Из корня проекта: `docker compose --profile test run --rm collector-tests` — тесты парсеров; `docker compose --profile data run --rm reviews <аргументы python>` — любой скрипт сборщика, например `-m scripts.collect_reviews --pilot 10` или `collect.py --help`. Для источников с ключами настройте собственный `.env` по `.env.example`. Сетевой сбор требует доступа к источникам и соответствующих разрешений провайдеров. Секретные ключи и сырые ответы API в эту папку не скопированы.

Офлайн-парсеры требуют предварительно собранных снимков в data/raw; данные основного приложения в ../data содержат готовые результаты, а не все исходные HTML/API ответы. Снимки исходного сборщика остаются в рабочей папке автора.

Проверки парсеров: `docker compose --profile test run --rm collector-tests`. Главные новые проходы: scripts/enrich_all_venues.py (типизированные цены, ограничения и статусы), ../scripts/normalize_data.py и ../scripts/refine_corpus.py (канонические POI, источники, описания и проверка кандидатов на дубли).

## Отзывы 2ГИС: первая страница

`scripts/collect_reviews.py` собирает первую страницу публичных отзывов (до 50 штук, сортировка 2ГИС `trust`) для каждого филиала 2ГИС из `../data/source_pois.jsonl`. Отзывы берутся только из HTML вкладки `/firm/{id}/tab/reviews`. Ссылки пагинации не используются и не сохраняются. Данные авторов (имена, фото, профили) не записываются. Ответ организации хранится отдельно от отзыва. Скорость — 1 запрос в секунду. При 401/403, повторном 429 или странице проверки доступа сбор останавливается.

Из корня проекта (`collector/output/` монтируется в контейнер):

```bash
docker compose --profile data run --rm reviews -m scripts.collect_reviews --pilot 10    # пробная выборка
docker compose --profile data run --rm reviews -m scripts.collect_reviews --limit 500   # следующие 500 филиалов, самые популярные первыми
docker compose --profile data run --rm reviews                                         # все оставшиеся
```

Повторный запуск продолжает с того места, где остановился: уже завершённые филиалы пропускаются. Результат пишется в `output/reviews_2gis/` (папка исключена из Git): `reviews_2gis.jsonl`, `branch_status.jsonl`, `review_targets.jsonl`, `review_collection_report.json`. Сбор неполный по определению: у филиалов с `has_more=true` остальные отзывы намеренно не собираются. Разница `total` и `total_for_request` — это отзывы без оценки, которые не входят в первую страницу.
