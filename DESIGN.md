# Astana Walk interface

Layout: a full-screen 3D map with a floating panel on the left (desktop) or a bottom sheet with a grip (phone, < 860px). The panel has four tabs: Маршрут (plan a walk), Места (places around the start), Помощник (chat), Город (events, guided walks, city gap map, settings).
Palette: deck-master `graphite-cyan` — graphite #14161B / #1F232B surfaces, cyan #00B8D9 → #7DF9FF accent, success #4ADE80, warning #FBBF24, danger #F87171. Dark is the default (`uiTheme` in localStorage); a light variant of the same palette is one toggle away in «Город». Tokens live in `frontend/src/tokens.css`.
Map: MapLibre GL with OpenFreeMap vector tiles (OSM data, no key). Buildings are extruded from the tiles' `render_height` (3D on by default, 2D/3D toggle remembered); the dark base style is retinted to the graphite palette. Pins are emoji discs in their category colour, numbered when they are an answer or a route; the start is a pulsing cyan dot with a label, the finish a flag. Routes are cyan lines on a dark casing, the way back dashed.
Planner: time segments (30 / 45 / 60 / 90 min, 2 / 3 h), «Туда и обратно» (the server returns a round trip ending at the start, with the return time) or «Только туда» (1–3 one-way options, optional finish landmark), a voice-ready request field, emoji wish chips that add their words to the request, the start card, «Где я сейчас», fine-tuning, and the main button with «Снова на старте к HH:MM». Wording is our own (no copy of the reference site).
Results: one quiet status line while the request runs (no step-by-step loading screen), the assistant's advice (listen button), option cards with a time ring (way there · visit · way back · spare), or a route timeline with arrival times, plan B per stop and the on-walk buttons (visited, closed, +15 min, cold, tired). Hovering a card lights its pin and route. Follow-up chips and a field refine the answer in place.
History: walks are kept only in the browser (`lib/history.ts`, localStorage, last 20 within 30 days): day, budget, mode, request words and places with planned / visited / closed; no coordinates (the start is a landmark key or a generic label). «Город» → «История» shows stats, repeats a walk, marks "been here" by tapping a place, deletes or clears; «Только новые места» sends the visited ids as `exclude_ids`. Answers mark places visited before.
Emoji: Noto Emoji images (Google), self-hosted in `frontend/public/emoji` and listed in `src/lib/emoji-manifest.json`: a still SVG, and for 67 of them a small Noto Animated WebP that plays while its button, card or pin is hovered (fetched on first hover, off under reduced motion). One per place kind (`frontend/src/lib/emoji.ts`, by subcategory, then category), preferring kinds Google animated. Regenerate with `python scripts/fetch_noto_emoji.py` (plus the weather emoji as arguments) when emoji change.
Motion: entrance rise, pin pop-in, chip and tile lifts, ring segments grow, emoji animations on hover; all off under `prefers-reduced-motion`.
Typography: self-hosted Inter (Latin, Cyrillic, Kazakh glyphs), no font CDN. Nothing below 11px.
Language: every UI string goes through `useT()` with ru/kk/en keys in `frontend/src/lib/i18n.ts`; `npm run build` fails on missing translations or hard-coded Cyrillic JSX text (`scripts/validate-i18n.mjs`). Data text from the backend (place names, warnings, model answers) stays as published.
Structure: `useWalk.ts` holds state and API actions; `App.tsx` decides what the map draws for the open screen; `MapView.tsx` wraps MapLibre; `ui/` has the screens (Planner, Results, PlaceDetail, StartPicker, Nearby, Chat, More) and the Ring; `components/` keeps the reused blocks (place Q&A, group panel, comfort note, afisha, guided walks, city gap page). Styles: `ui.css` for the interface, `legacy.css` for the reused blocks.
Accessibility: `tests/a11y.spec.ts` runs axe (WCAG 2.1 A/AA) for light/dark × ru/kk/en × desktop/mobile on the planner, the nearby list and an open place.
Loading, empty, network/model failure and unknown data are explicit. Geolocation occurs only on button activation.
